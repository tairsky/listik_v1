КАК ЗАПУСТИТЬ ЛИСТИКА НА СВОЁМ КОМПЬЮТЕРЕ

1. Один раз установите Node.js: https://nodejs.org (большая кнопка LTS).
2. Распакуйте архив в папку listik.
3. Windows: дважды щёлкните start.bat.
   Mac: в Терминале выполните (архив должен лежать на рабочем столе):
       cd ~/Desktop && unzip -o listik.zip && cd listik && node server.js
   Потом откройте в браузере http://localhost:3000/
4. При запуске в окне пишется, сколько кабинетов найдено и в какой папке они лежат. Если после обновления там "0", а вы
   создавали кабинеты раньше, значит, вы запустили Листика из другой папки. Кабинеты лежат в папке storage внутри той папки,
   из которой запущен сервер. Чтобы перенести их, скопируйте папку storage целиком в новую папку listik.
5. Остановить: Control + C (Mac) или закрыть окно (Windows). Останавливайте так, а не выключением компьютера:
   при остановке сервер дописывает последние результаты.

ПИСЬМА (регистрация, восстановление пароля)
После регистрации родителю уходит письмо «Кабинет создан». На странице входа есть «Забыли пароль?»: на почту приходит ссылка на новый пароль (действует час).
Письма отправляет сервис Resend (resend.com). В файл .env или в настройки хостинга (Render) добавьте:
   RESEND_API_KEY=re_...                       ключ из кабинета Resend
   MAIL_FROM=Листик <hello@ваш-домен.kz>      адрес отправителя; домен нужно подтвердить в Resend
   SITE_URL=https://ваш-сайт.kz                адрес сайта для ссылок в письмах
Пока ключа нет, письма не уходят, а записываются в storage/outbox.log (можно проверить на своём компьютере).
Регистрация и вход открываются через «Кабинет родителя» (есть на главной, в тарифах и на странице выбора).

ЕСЛИ РОДИТЕЛЬ ЗАБЫЛ PIN (пароль он теперь восстанавливает сам по письму; PIN по-прежнему меняет владелец или сам родитель в кабинете)
Остановите Листика и в папке listik выполните:
   node admin.js list                             показать все кабинеты
   node admin.js password почта@пример.kz НОВЫЙ_ПАРОЛЬ   задать новый пароль (от 8 символов)
   node admin.js pin почта@пример.kz 4829         задать новый PIN (4 цифры)
   node admin.js delete почта@пример.kz           удалить кабинет
Потом запустите Листика снова.

Тестировать с телефона: телефон и компьютер в одной Wi-Fi, откройте http://АДРЕС_КОМПЬЮТЕРА:3000/listik.html
Начать с чистого листа: остановите Листика и удалите папку storage.

СТРАНИЦЫ
   http://localhost:3000/              главная: три модуля (Репетитор, Домашнее задание и НИШ пока «Скоро»)
   http://localhost:3000/tutor.html    лендинг модуля «Репетитор»
   http://localhost:3000/start.html    мастер выбора: язык, предмет, класс, раздел
   http://localhost:3000/listik.html   программа Листик (после выбора задачи идут по очереди)
Разделы и порядок задач задаются в data/private/tasks.json: поля "sections" и "section" у каждой задачи.
Шрифты лежат в папке fonts (Unbounded, Onest, Caveat), интернет для них не нужен.
